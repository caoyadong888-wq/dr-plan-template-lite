# 联系人名单

担任计划里那些角色的人。这份名单的分享副本只使用 `@example.com`。事件负责人的示例邮箱是 `incident-lead@example.com`。不要写电话号码。

## 名单

- 事件负责人：{{INCIDENT_LEAD_NAME}}，{{INCIDENT_LEAD_EMAIL}}
- 备份操作人：{{BACKUP_OPERATOR_NAME}}，{{BACKUP_OPERATOR_EMAIL}}
- 沟通：{{COMMS_NAME}}，{{COMMS_EMAIL}}
- 服务所有者：{{SERVICE_OWNER_NAME}}，{{SERVICE_OWNER_EMAIL}}

如果人选按周轮换，用一句话写上轮值。姓名记号是团队希望写进计划的名字，不是厂商账号编号。

## 渠道

- 状态邮箱：{{STATUS_EMAIL}}
- 团队内部的房间名：{{ROOM_NAME}}
- 计划作者：{{REVISION_EMAIL}}

状态邮箱是看这件事的人会去看的地方。房间名是内部标签。本包不写聊天产品的名字，也不写 API 字段。以后如果要把工具接到那个房间，请核对上游文档。
